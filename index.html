03 / How I work

How I work

  1. 01

    Play it back before building.

    At the end of each workshop you hear what I understood, and you correct it before anything is built.

  2. 02

    Configuration before code.

    Standard Business Central first. Code only where setup cannot do the job.

  3. 03

    Requirements become tests.

    Each agreed rule becomes a check that runs after every build.

  4. 04

    It works, and nothing else breaks.

    I use AI tools in my work, and I'm happy to stick to the tools your organisation has approved. Before anything reaches you, I make sure it works and does not break what you already have.

  5. 05

    Your data stays with you.

    Demo data shaped like your business, or tools that run inside your own tenant. Nothing of yours goes anywhere without your consent.

  6. 06

    Built on Microsoft, not against it.

    Standard APIs and the platform as Microsoft ships it, so each release wave is an upgrade and not a rescue.
